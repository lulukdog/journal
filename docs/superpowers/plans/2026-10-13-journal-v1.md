# 每日日记 App v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个能记录、能回看、能被提问的私人日记 Web 应用，部署在 39.96.68.27:10002。

**Architecture:** 单个 FastAPI 应用 + SQLite 单文件 + 一个 HTML 页面。没有构建步骤，没有 Node，没有 Docker。systemd 管进程，systemd timer 管每晚收口。所有记录先落库、再调模型，模型挂了不影响记录。

**Tech Stack:** Python 3.10 / FastAPI / uvicorn / httpx / SQLite (stdlib) / FTS5 / 原生 JS

**Spec:** `docs/superpowers/specs/2026-10-13-daily-journal-design.md`

## Global Constraints

- 运行时 Python 3.10（服务器已装），**不引入 Node / Docker / nginx**
- 数据库唯一 SQLite 文件 `/var/lib/journal/journal.db`，**不用 Postgres**（内存只有 1.7 GB）
- 监听 `0.0.0.0:10002`，uvicorn 直连
- 一天的边界 **04:00 Asia/Shanghai**：`04:00` 之前算前一天
- 检索只用 **FTS5 + trigram**，不上向量
- 状态分 `mood` 取 **-2..2 的整数**，`mood_label` 用用户自己的话，**不用临床词**
- 第一版**不做推送**、**不做 HTTPS**、**不做心理诊断或抑郁评分**
- 认证：长随机 token + HttpOnly + SameSite=Lax cookie；**token 只放 `.env`，永不进代码库**
- 图片：原图全精度存盘；发给模型的那份长边压到 ≤1568px
- 模型默认 `deepseek-v4.1-flash`，深度分析可切 `gpt-5.6-luna`，**模型名是配置项**
- 所有对外文案用中文

## Review Focus

这些是 spec 暗示、但没有哪个任务的测试天然覆盖的输入，最可能让真人踩到：

1. **空输入 / 纯空白** —— 不该产生一条空记录，也不该调模型
2. **模型超时或返回非法 JSON** —— 「记一笔」必须照常成功；「问它」必须给出人话错误，不能 500 白屏
3. **跨天边界** —— 03:59 和 04:01 两条记录必须落在不同的 `day`
4. **未登录访问 `/media/<path>`** —— 必须挡住。图片比文字更敏感，这是最容易漏的一道门
5. **首次使用**（memories 空、days 空、从没说过话）—— 页面不能空白、报错，要直接进引导访谈
6. **图片过大或格式不支持** —— 返回明确的拒绝理由，不能 500

每个任务里，属于它那块代码的检查，写成该任务的一个测试步骤。
